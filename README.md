# คู่มือการใช้งานระบบติดตามสถานะ กยศ. (Looker Studio Tracker)

เอกสารนี้ระบุวิธีการใช้งานระบบสำหรับผู้กู้ยืมเงิน กยศ. เพื่อรับการแจ้งเตือนเมื่อมีการเปลี่ยนแปลงสถานะผ่าน Looker Studio

---

## 1. การลงทะเบียนเพื่อรับการแจ้งเตือน

ผู้ใช้งานสามารถสมัครรับการแจ้งเตือนการอัปเดตสถานะได้โดยการกรอกข้อมูลผ่านแบบฟอร์มลงทะเบียน:

👉 **[แบบฟอร์มลงทะเบียนรับการแจ้งเตือน กยศ.](https://forms.gle/G88boc8n8LZxG9ez9)**

ข้อมูลที่ต้องระบุในแบบฟอร์ม:

1. **ชื่อ - นามสกุล** ของผู้กู้ยืม
2. **อีเมล** ที่ต้องการใช้รับการแจ้งเตือน (เมื่อสถานะเปลี่ยน ระบบจะจัดส่งอีเมลแจ้งเตือนไปยังอีเมลนี้โดยอัตโนมัติ)
3. **รหัสนักศึกษา / รหัสนิสิต** (เพื่อใช้ระบุและกรองข้อมูลส่วนตัวในหน้าแดชบอร์ด)
4. **ลิงก์หน้ารายงาน Looker Studio** (ลิงก์รายงานผลการยื่นกู้ของมหาวิทยาลัย โดยลิงก์ต้นฉบับหลักสำหรับใช้เข้าตรวจสอบคือ [Looker Studio Dashboard](https://datastudio.google.com/u/0/reporting/8a4c4d64-1bd1-4866-95c6-265189ee53af/page/DlByD))

---

## 2. ขั้นตอนการทำงานของระบบ

เมื่อกรอกข้อมูลลงทะเบียนเรียบร้อยแล้ว ระบบจะดำเนินการให้โดยอัตโนมัติ:

1. **การตรวจสอบข้อมูล:** ระบบจะเข้าไปตรวจสอบข้อมูลสถานะในรายงาน Looker Studio ของคุณทุก ๆ 2 ชั่วโมง
2. **การเปรียบเทียบสถานะ:** หากข้อมูลล่าสุดบนหน้าแดชบอร์ดตรงกับประวัติเดิม ระบบจะไม่มีการส่งอีเมลใด ๆ เพื่อป้องกันการส่งอีเมลซ้ำรบกวนผู้ใช้งาน
3. **การส่งอีเมลแจ้งเตือน:** หากตรวจพบการเปลี่ยนแปลงสถานะ (เช่น เจ้าหน้าที่รับเอกสารแล้ว, มีเอกสารต้องแก้ไข หรือนำส่งเอกสารให้ธนาคารเรียบร้อยแล้ว) ระบบจะส่งอีเมลแจ้งเตือนพร้อมตารางสรุปสถานะล่าสุดไปที่อีเมลของคุณทันที

---

## 3. สิ่งที่จะได้รับในอีเมลแจ้งเตือน

เมื่อเกิดการอัปเดตสถานะและได้รับอีเมลจากระบบ ผู้ใช้งานสามารถเปิดดูรายละเอียดได้ทันที ดังนี้:

* **ข้อมูลผู้กู้ยืม:** แสดง ชื่อ-นามสกุล, รหัสนักศึกษา และประเภทผู้กู้ยืม
* **ขั้นตอนที่ 1 (การเสนอขอกู้ยืม):** แสดงสถานะการรับเอกสารประกอบคำขอ และวันที่ตรวจเอกสารล่าสุด
* **ขั้นตอนที่ 2 (การส่งแบบเบิกเงินกู้ยืม):** แสดงสถานะการเตรียมส่งเอกสารให้ธนาคาร สถานะส่งธนาคาร และสถานะการตรวจเอกสารของธนาคาร
* **รายการแจ้งแก้ไข (หากมี):** หากมีเอกสารที่ต้องแก้ไข ระบบจะดึงรายละเอียด เช่น เอกสารจุดที่ต้องแก้ไข, วันที่กำหนดให้ส่ง และช่องทางการส่งเอกสารแก้ไข เพื่อให้คุณดำเนินการแก้ไขได้ทันเวลา
* **ลิงก์หน้าหลัก:** มีปุ่มกดที่สามารถคลิกเข้าไปดูหน้ารายงาน Looker Studio Dashboard ต้นฉบับได้ทันที
