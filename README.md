# ระบบติดตามสถานะ กยศ. ผ่าน Looker Studio (Looker Studio Tracker)

ระบบอัตโนมัติสำหรับตรวจสอบความเปลี่ยนแปลงของสถานะการยื่นกู้ กยศ. จากหน้า Looker Studio Dashboard ของมหาวิทยาลัย และส่งอีเมลแจ้งเตือนผู้ใช้งานทันทีเมื่อมีการอัปเดตสถานะ (รองรับผู้ใช้งานหลายคนพร้อมกันแบบ Multi-User)

---

## 🛠 สถาปัตยกรรมระบบ (System Architecture)
- **Engine:** พัฒนาด้วย Python และ Playwright เพื่อจำลองการเปิดเว็บเบราว์เซอร์จริง ป้อนข้อมูล ค้นหา/กรองข้อมูลรหัสนักศึกษา (Filter) และดึงผลลัพธ์จาก Looker Studio ซึ่งเป็น Client-side Javascript ที่ดึงข้อมูลทั่วไปได้ยาก
- **Deployment:** รันฟรี 100% ผ่าน **GitHub Actions** (รันอัตโนมัติด้วย Cron Job ทุก ๆ 2 ชั่วโมงในช่วงเวลาราชการ)
- **State Management:** บันทึกสถานะล่าสุดไว้ในไฟล์ `state.json` บน Git Repository โดยตรง เมื่อสถานะเปลี่ยน ระบบจะอัปเดตไฟล์นี้กลับขึ้นไปบน Git ให้เองอัตโนมัติโดยไม่จำเป็นต้องใช้ Database ภายนอก

---

## 📁 โครงสร้างไฟล์
- `tracker.py` : สคริปต์หลักสำหรับจำลองผู้ใช้เข้าเว็บ ค้นหาข้อมูล เปรียบเทียบสถานะ และส่งอีเมล
- `users.json` : รายชื่อผู้ใช้ที่ต้องการให้ระบบเข้าไปเช็คสถานะและส่งอีเมล (สำหรับทดสอบในเครื่อง)
- `state.json` : บันทึกข้อมูลและประวัติสถานะล่าสุดของแต่ละผู้ใช้
- `requirements.txt` : รายการ Libs ที่ต้องใช้หลัก ๆ คือ Playwright
- `.github/workflows/tracker.yml` : ตั้งค่า GitHub Actions สำหรับตั้งเวลารันอัตโนมัติ

## 📝 วิธีให้ผู้ใช้งานกรอกข้อมูลตนเอง (Google Forms & Sheets Integration)

เพื่อให้ผู้ใช้งาน (นักศึกษา) สามารถเข้ามากรอกข้อมูลของตนเองได้ง่ายๆ โดยที่คุณไม่ต้องเข้าไปแก้ไขโค้ดหรือเขียนระบบสมัครสมาชิกเองให้ยุ่งยาก ระบบนี้ได้รับการออกแบบมารองรับการดึงข้อมูลจาก **Google Sheets** ที่ผูกกับ **Google Forms** ได้โดยตรง:

### 1. วิธีสร้างฟอร์มกรอกข้อมูล
1. สร้าง **Google Form** ขึ้นมาหนึ่งฟอร์ม โดยใส่คำถามดังนี้:
   * **ชื่อ-นามสกุล** (แบบคำตอบสั้น)
   * **อีเมล** (สำหรับรับแจ้งเตือนเมื่อสถานะเปลี่ยน)
   * **ลิงก์ Looker Studio Dashboard** (ลิงก์รายงานผล กยศ.)
   * **รหัสนักศึกษา / เลขบัตรประชาชน** (รหัสที่ต้องใช้กรอกฟิลเตอร์ค้นหาในบอร์ด)
2. เมื่อสร้างฟอร์มเสร็จแล้ว ให้ไปที่แท็บ **การตอบกลับ (Responses)** -> คลิกไอคอน **Google Sheets (สร้างสเปรดชีต)** เพื่อเชื่อมฟอร์มเข้ากับ Google Sheets
3. ในหน้ารายการข้อมูล Google Sheets:
   * ไปที่เมนู **ไฟล์ (File)** -> **แชร์ (Share)** -> **เผยแพร่ไปยังเว็บ (Publish to web)**
   * ในแถบตั้งค่า ให้เลือกสเปรดชีตย่อยที่ต้องการ (เช่น *ฟอร์มตอบกลับ 1*) และเลือกประเภทผลลัพธ์เป็น **"ค่าที่คั่นด้วยจุลภาค (.csv)" (Comma-separated values (.csv))**
   * กดปุ่ม **เผยแพร่ (Publish)** และคัดลอกลิงก์ URL ผลลัพธ์ที่ได้ (ตัวอย่างลิงก์: `https://docs.google.com/spreadsheets/d/e/.../pub?output=csv`)
4. นำลิงก์ CSV นี้ไปใส่ในตัวแปรความลับ GitHub Secret ชื่อ **`GOOGLE_SHEET_CSV_URL`** ในขั้นตอนถัดไป

เมื่อตั้งค่าเสร็จแล้ว ทุกครั้งที่มีคนเข้ามากรอกแบบฟอร์ม ข้อมูลจะถูกบันทึกลง Google Sheets และระบบ GitHub Actions ของเราจะดึงข้อมูลผู้ใช้ล่าสุดมาสแกนและส่งเมลแจ้งเตือนให้ทันทีแบบเรียลไทม์!

## 🚀 ขั้นตอนการติดตั้งและการนำขึ้น Production

### 1. วิธีรับรองความปลอดภัยของข้อมูลผู้ใช้ (แนะนำ)
หากคุณนำโครงการนี้ไปไว้บน Public GitHub Repository แนะนำให้เก็บข้อมูลส่วนตัว (อีเมลและรหัสนักศึกษา) ไว้ใน **GitHub Secrets** เพื่อไม่ให้ใครเห็นข้อมูลในไฟล์โค้ดสาธารณะ:

นำข้อมูลทั้งหมดไปสร้างเป็น GitHub Secrets ดังนี้:

| Secret Name | Description | Example Value |
|-------------|-------------|---------------|
| `SENDER_EMAIL` | อีเมลหลักสำหรับส่งแจ้งเตือน (แนะนำเป็น Gmail) | `mybot@gmail.com` |
| `SENDER_PASSWORD` | รหัสผ่านแอปพลิเคชัน (App Password) ของอีเมลผู้ส่ง | `abcd efgh ijkl mnop` |
| `GOOGLE_SHEET_CSV_URL` | ลิงก์ CSV ที่ได้จากการเผยแพร่ Google Sheet ไปยังเว็บ (แนะนำสำหรับรองรับหลายผู้ใช้ลงทะเบียนเอง) | `https://docs.google.com/spreadsheets/d/e/.../pub?output=csv` |
| `USERS_CONFIG` | (เลือกใส่) ข้อมูลผู้ใช้หลายคนในรูปแบบ JSON String (กรณีไม่ใช้ Google Sheets) | `[{"id":"user1","name":"สมชาย","email":"somchai@gmail.com","url":"...","student_id":"64010001"}]` |

---

### 2. วิธีตั้งค่า Gmail App Password (สำหรับอีเมลผู้ส่ง)
หากใช้ Gmail ในการส่งอีเมลแจ้งเตือน คุณต้องสร้าง **App Password** เนื่องจาก Gmail ไม่อนุญาตให้ล็อกอินด้วยรหัสผ่านหลักปกติ:
1. เข้าหน้าบัญชี Google ของอีเมลผู้ส่ง -> ไปที่ **ความปลอดภัย (Security)**
2. เปิดการใช้งาน **การยืนยันแบบสองขั้นตอน (2-Step Verification)**
3. ค้นหาคำว่า **"รหัสผ่านสำหรับแอป" (App Passwords)** ในช่องค้นหาด้านบนของหน้าตั้งค่าบัญชี
4. สร้างรหัสผ่านสำหรับแอป ตั้งชื่อแอปว่า `LookerStudioTracker`
5. คัดลอกรหัสผ่าน 16 หลักที่ได้ นำไปใส่เป็นค่าใน `SENDER_PASSWORD` (ไม่ต้องเว้นวรรค)

---

### 3. วิธีเปิดใช้งานบน GitHub Actions (Production)
1. นำโฟลเดอร์โครงการนี้อัปโหลดขึ้น **GitHub Repository** ของคุณ (สร้างเป็น Private Repository ได้ฟรีหากไม่อยากตั้งค่า GitHub Secrets)
2. ไปที่แท็บ **Settings** ของ Repository -> เลือกเมนู **Secrets and variables** -> คลิก **Actions**
3. กดปุ่ม **New repository secret** เพื่อสร้าง Secrets ทั้ง 3 ตัว (`SENDER_EMAIL`, `SENDER_PASSWORD`, `USERS_CONFIG`) ตามตารางด้านบน
4. ไปที่แท็บ **Actions** ของ Repository บนเว็บ GitHub และคลิกเลือก Workflow **"Looker Studio Tracker"**
5. คลิกปุ่ม **Run workflow** เพื่อทดลองรันครั้งแรกด้วยตนเองทันที

*หมายเหตุ: สคริปต์ตั้งเวลารันอัตโนมัติ (Cron) ไว้ทุก 2 ชั่วโมงระหว่างเวลา 08:00 - 22:00 น. ของประเทศไทย สามารถปรับแต่งรอบได้ที่ไฟล์ `.github/workflows/tracker.yml`*

## 💻 วิธีการรันและทดสอบในเครื่องคอมพิวเตอร์ของคุณ (Local Testing)

1. **ติดตั้ง Python (หากยังไม่มี):**
   ตรวจสอบเวอร์ชัน Python ในเครื่อง:
   ```bash
   python3 --version
   ```

2. **ติดตั้ง Dependencies:**
   เปิด Terminal ในโฟลเดอร์นี้และรันคำสั่ง:
   ```bash
   pip3 install -r requirements.txt
   playwright install chromium
   ```

3. **ตั้งค่าไฟล์สำหรับทดสอบ:**
   แก้ไขข้อมูลในไฟล์ `users.json` และทดลองกรอกข้อมูลจริงของคุณ

4. **ตั้งค่าตัวแปรใน Environment (ก่อนรัน):**
   ```bash
   export SENDER_EMAIL="your-email@gmail.com"
   export SENDER_PASSWORD="your-app-password"
   ```

5. **เริ่มการทดสอบ:**
   รันสคริปต์พร้อมคำสั่งเปิดเบราว์เซอร์ให้เห็นหน้าจอจริงด้วยแฟล็ก `--headful` เพื่อดูการจำลองเข้าเว็บกรองข้อมูลรหัส:
   ```bash
   python3 tracker.py --headful
   ```
